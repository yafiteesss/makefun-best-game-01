**Lumen Drift** — steer a little lantern-ship through the Dusk Reefs. Gather light-motes to charge the beacon and reach the target score before your lamp runs dry; dodge the reef rocks, chain pickups into combos, and dash through danger at the cost of fuel. Five levels, each a darker reef with faster rocks. A complete game: title, play, pause, beacon-lit and game-over screens, HUD with score, hull, fuel and combo, synthesized sound, and a restart — all in plain static files, no network.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```

Play with the mouse or WASD / arrow keys, Space to dash, P to pause, M to mute. The entry program hands the game in with `MAKEFUN_OUTPUT_DIR=out node main.ts`.
